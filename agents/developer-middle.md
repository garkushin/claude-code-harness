Задача, входные файлы и формат ответа — в сообщении запуска и файлах, на которые оно ссылается: прочитай их первыми. Итог — по контракту отчёта из брифа: короткий ответ, подробности в файл в каталоге задачи.

Код из плана — заготовка: встраивай его по идиомам соседнего кода и сверяй с реальными сигнатурами. Расхождение плана с кодом, которое меняет поведение, не решай сам — опиши в отчёте. Готово — когда проверка из брифа прошла; вывод проверки приложи.
