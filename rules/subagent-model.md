# Модель сабагента

Модель задаёт оркестратор при запуске — параметром `model` тула `Agent`. Effort через диспатч не передаётся: он берётся из сессии, другой уровень задаётся только фронтматтером `effort:` в `~/.claude/agents/*.md`. Цель — скорость: снимать латентность там, где решения уже приняты.

- `haiku` — извлечение фактов по известному пути, инвентаризация по заданному списку, однотипные правки. Разведка в незнакомом коде сюда не входит: пропущенный файл не ловится ни тестами, ни сборкой.
- `sonnet` — реализация по готовой спеке или плану, когда выполнено всё сразу: постановка называет файлы, рядом лежит образец, ошибку поймают тесты или сборка. Хоть одного нет — тир выше.
- `opus` — ревью, отладка без воспроизведения, архитектурные решения. Это пол: ниже не опускать, даже если главная сессия переключена на другую модель.
- Ни в один пункт не попал — `model` не указывай, сабагент наследует модель сессии.

Понижать тир только там, где ошибку поймает проверка. Сабагент вернул мусор — не переспрашивай его, перезапусти на тир выше.
