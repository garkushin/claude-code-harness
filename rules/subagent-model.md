# Модель и effort сабагента

Тир сабагента задаёт оркестратор при запуске — выбором `subagent_type`.

- `opus-medium` — реализация по готовому брифу, спеке или плану, правки и доки по списку: решения уже приняты, ошибку поймают тесты или сборка.
- `opus-high` — ревью кода и доков, сверка фактов о чужих системах, предполётные проверки планов, отладка без воспроизведения.
- `opus-xhigh` — исследование незнакомой системы или кодовой базы, архитектура и выбор между вариантами, решения с неочевидными последствиями. Дороже по токенам и времени: не для ревью и не для исполнения.
- Скилл велит диспатчить `general-purpose` (superpowers и другие) — подставляй тип по тем же признакам; промпт из скилла не меняй.
- Ни в один пункт не попал — `general-purpose`: модель и effort сессии.

Параметр `model` при вызове меняет только модель — effort остаётся из определения агента. Сабагент вернул мусор — не переспрашивай его, перезапусти на тир выше: `opus-medium` → `opus-high` → `opus-xhigh`.
