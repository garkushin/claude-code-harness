# Модель и effort сабагента

Тир сабагента задаёт оркестратор при запуске — выбором `subagent_type`. Effort живёт только во фронтматтере определения агента: у тула `Agent` параметра effort нет, а встроенные типы (`general-purpose`, `Explore`) берут effort сессии.

- `opus-medium` — реализация по готовому брифу, спеке или плану, правки и доки по списку: решения уже приняты, ошибку поймают тесты или сборка.
- `opus-high` — ревью кода и доков, сверка фактов о чужих системах, отладка без воспроизведения, архитектурные решения.
- Скилл велит диспатчить `general-purpose` (superpowers и другие) — подставляй `opus-medium` или `opus-high` по тем же признакам; промпт из скилла не меняй.
- Ни в один пункт не попал — `general-purpose`: модель и effort сессии.

Параметр `model` при вызове меняет только модель — effort остаётся из определения агента. Сабагент вернул мусор — не переспрашивай его, перезапусти на тир выше: `opus-medium` → `opus-high`.
